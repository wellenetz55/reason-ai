# 画面3：展開画面

使う人: `customer_admin`（状態: week6_8 / extended / grace / advisor）。operator はレビュー側から同じ画面を見る。

## 1. 上部固定

確認②で封をした1位の提供価値（②）、⑧つかみ、⑨ビコーズ。変更不可。1位が未封なら画面全体をロック（「確認②で1位が確定すると使えます」）。

## 2. 生成フォーム

- 接点: 営業トーク／価格説明／Web（FV＋4つの不に先回りするブロック）／採用EVP／見積の言葉／社内共有用1枚／その他
- 意識レベル: 無意識（80%）／問題意識（15%）／解決意識（5%）
- 任意: 使う行の追加指定（1位以外の行を根拠として束ねる）

## 3. 生成物の構造

ブロック順は固定: フック → 共感 → 証拠 → 緊急性 → CTA。各ブロックに:
- 本文
- 使った行（行No・列）
- 根拠タグ（事実／要確認／仮説）。**要確認・仮説の内容は本文に使わない**。材料が無いブロックは空欄＋「材料なし（宿題: ○○）」と表示する。空欄をAIが埋めることはしない
- operator のみ: 使った回天／脳科学手法（`techniques_json`）。顧客向けAPIレスポンスには含めない

意識レベルとステップの対応（AIの内部ルール）: 無意識→STEP1を厚く／問題意識→STEP2・5／解決意識→STEP3・4。

## 4. 対応表

生成物の下に「どの行を使ったか／使わなかった行と理由（要確認・仮説のため）」の表。顧客にも見せる（透明性）。手法名は出さない。

## 5. 保存とレビュー

- 保存 → `awaiting_review`。operator が承認／差し戻し
- 承認済みは活用パッケージに収納
- 生成カウンタ: advisor は月10件、grace は3件。残数を常時表示。上限到達で「来月か、ベレネッツに相談」（advisor）／顧問の案内（grace）

## 6. 活用パッケージ（第3層）

承認済み展開物を束ねる画面。表紙に Q1 before / after。
- 接点マップ（どの提供価値をどこで使うか）
- 営業トーク台本／価格説明／Web原稿／採用EVP／見積の言葉／社内共有用1枚／月次運用の型
- 提供価値シート生データ（Excel）へのリンク
- PDF/Docx 書き出し（手法名を含めない）
